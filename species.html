品種百科：天然演化實驗室的傑作

蘇拉威西的古老湖泊像一間緩慢運作的天然實驗室，將礦物、水溫、微生物與時間， 淬鍊成紅、藍、白交錯的生命色彩。

Wild vs Selective / 先分清楚兩件事

野生原種，還是人工選育色系？

蘇拉威西蝦最容易混淆的一點：市面上很多名字其實是同一個物種的人工選育色系， 而不是不同物種。分清楚這件事，才看得懂血統與價格。

Wild Type

野生原種

各自是獨立物種，來自不同湖泊：紅衣主教（Caridina dennerli，瑪塔諾湖）、 藍腳波索（C. caerulea，波索湖）、小丑蝦（C. woltereckae，圖蒂湖）等。

Selective Line

人工選育色系

金眼藍幽靈、白蘭花、銀河、虎紋都是從紅衣主教（C. dennerli）累代選育出的色系， 野外並不存在，也是本站旗艦品的來歷。

為什麼優先選擇人工累代個體？

蘇拉威西多數野生蝦種被 IUCN 列為易危至極危，棲地僅限少數古老湖泊。 選擇人工累代繁殖的個體，能降低野採壓力，也讓體質更適應缸內環境——這既是負責任的選擇，也是穩定發色的基礎。

Species Flock / 長得像卻不同種

為什麼很多蘇蝦「長得像」卻是不同種？

上一段說「很多名字其實是同一物種的色系」；反過來也成立——蘇拉威西古老湖泊裡有一群外觀極相似的野生種。 德國柏林自然史博物館 von Rintelen 團隊證實：牠們泡進酒精保存後幾乎無法用形態分辨，唯一可靠的辨識靠活體體色斑紋。

Live Colour ID

要靠「活體體色」才分得出

紅線（C. striata）、小丑（C. woltereckae）、紅蘭花（C. glaubrechti）三種吻形相近， 保存標本幾乎一模一樣，只有活著時的體色斑紋能明確區分。

Cryptic Species

連 DNA 才揪得出的隱蔽種

von Rintelen 等人 2007 年證明：原本被當成同一種的兩個色型，形態挑不出差異， DNA 卻顯示是兩個不同的種。體色在此扮演物種辨識的關鍵角色。

那「黃環」和「黃頰」呢？

這兩個常被當成不同蝦，但就目前已發表的分類學，兩者都是黃鼻蝦 Caridina spinata 的體色變異—— 「紅底＋黃色橫帶繞過腹部」正是 spinata 的招牌特徵，橫帶繞過圓柱狀腹節就成了「環」。 要真正證明是不同種，得靠 DNA 條碼，光看外觀不算數。

No Hidden Variants

依來源分類

所有品系直接平鋪顯示；篩選只幫助聚焦，不把資訊藏起來。

Wild Type · Lake Matano

經典白襪蝦（紅衣主教）

Caridina dennerli

原生於瑪塔諾湖的野生原色種，鮮紅底色配白點與白色前足。覓食時白手連續撥動， 是最容易辨識的蘇蝦標誌，也是眾多選育色系的血統源頭。

  • 學名：Caridina dennerli
  • 來源：瑪塔諾湖（野生原色）
  • 難度：2/10
  • 展示重點：紅潤體色、白手節奏、黑岩對比
Selective Line · 人工選育

金眼藍幽靈

Caridina dennerli var. Golden-Eye Blue Ghost

以紅衣主教累代選育而成的藍色色系，野外並不存在。金屬藍體色配橘金複眼， 是本站旗艦品系；照護難度與原生種相近，適合作為高端收藏缸主視覺。

  • 學名：Caridina dennerli（選育色系）
  • 來源：人工選育（瑪塔諾湖血統）
  • 難度：2/10
  • 展示重點：金屬藍光、橘金複眼、穩定累代

白蘭花

Caridina dennerli var. White Orchid

同樣源自瑪塔諾湖 dennerli 的選育色系（又稱 Starry Night），棕褐底色綴以淺色星點。 素材庫尚無可靠標定的白蘭花照片，暫以標本位置保留。

Wild Type · Lake Poso

藍腳波索

Caridina caerulea

來自波索湖的野生物種，與瑪塔諾湖的 dennerli 系是不同的種；帶藍色調、適應性最佳， 是公認最好養的蘇蝦，適合建立第一座蘇蝦缸。

  • 學名：Caridina caerulea
  • 來源：波索湖（野生物種）
  • 難度：1/10（最好養）
  • 展示重點：藍色調、入門友善、低維護系統

命名陷阱：別被「顏色俗名」騙了

藍幽靈 Blue Ghost（本站選育，C. dennerli 藍化）≠ 藍月 Blue Moon（C. trifasciata，香港軟酸水）≠ 藍魔 Blue Devil／OEBD（C. cantonensis 系，華南軟酸水）。 三者不同種、水質需求相反，只有藍幽靈屬蘇拉威西硬鹼水系。同理「紅蜜蜂」多指軟酸水的蜜蜂蝦，並非蘇拉威西原生。
